# 项目审查结论

## 审查前状态

原目录只有三份原始 CSV、一张目标界面截图和 `SinglePrediction.md`。说明文档把若干功能写成“当前实现”，但实际上没有源码、依赖、模型、配置、测试、README、Git 忽略规则或 Git 仓库，因而无法运行。

## 本次补齐范围

- 统一离线/在线特征契约，避免训练和推理使用不同字段。
- 将主动互动定义为：点赞、分享、评论、关注创作者、重播任一发生。
- 生成 `processed_interactions.csv`；不把行为结果或 `engagement_score` 放入特征，防止目标泄漏。
- 训练逻辑回归、随机森林、梯度提升树和 LightGBM，以验证集 ROC-AUC 选择最佳模型。
- FastAPI 提供 `/health` 与 `/predict`；模型缺失、ID 不存在和输入非法时有明确错误。
- Streamlit 提供单条预测、API 状态、概率仪表盘和响应 JSON。
- 增加基础自动测试、环境示例、部署说明和监控占位说明。

所有交互中的 `user_id` 和 `video_id` 都能在主表中找到。主动互动标签的正例率约为 27.79%。原始交互文件约 139 MB，不能直接通过普通 Git 推送到 GitHub（单文件上限 100 MB）。

## 尚未纳入一期的内容

批量预测、分析面板、模型解释（例如 SHAP）、身份认证、持久化画像服务、容器化、CI/CD、生产监控和线上再训练都属于合理的下一阶段，不应伪装成一期已完成。

## 本地验证结果（2026-08-03）

- 全量生成 500,000 行、36 列训练表；缺失值为 0，正例率为 27.792%。
- 全量 80/20 分层划分后，ROC-AUC：逻辑回归 0.564289、随机森林 0.561294、梯度提升树 0.565453、LightGBM 0.569940。
- 按预设 ROC-AUC 规则，最终选择 LightGBM；训练 400,000 行，验证 100,000 行。
- 自动测试 3 项全部通过；真实 API 请求返回 200，未知 ID 返回 404，非法范围返回 422。
- FastAPI 健康检查成功，Streamlit 无头模式启动成功。

这些 AUC 只略高于 0.5，说明当前可在线获得的字段对主动互动预测能力有限。它是数据/特征信号的诚实基线，不应通过引入交互结果字段来人为抬高。
